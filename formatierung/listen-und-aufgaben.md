## Ungeordnete Liste

```md
- Erster Punkt
- Zweiter Punkt
  - Eingerückt
    - Noch eine Ebene
      - Und noch eine
- Dritter Punkt
```

- Erster Punkt
- Zweiter Punkt
  - Eingerückt
    - Noch eine Ebene
      - Und noch eine
- Dritter Punkt

## Geordnete Liste

```md
1. Erster Schritt
2. Zweiter Schritt
   1. Teilschritt
   2. Noch einer
3. Dritter Schritt
```

1. Erster Schritt
2. Zweiter Schritt
   1. Teilschritt
   2. Noch einer
3. Dritter Schritt

## Gemischt

```md
1. Ein Schritt
   - mit einer Anmerkung
   - und noch einer
2. Der nächste Schritt
```

1. Ein Schritt
   - mit einer Anmerkung
   - und noch einer
2. Der nächste Schritt

## Aufgabenliste

```md
- [ ] Offen
- [x] Erledigt
- [ ] Mit Unterpunkten
  - [x] Teil eins
  - [ ] Teil zwei
```

- [ ] Offen
- [x] Erledigt
- [ ] Mit Unterpunkten
  - [x] Teil eins
  - [ ] Teil zwei

> [!tip] Erledigtes wird nicht nur ausgegraut
> Ein erledigter Punkt bekommt gedämpfte Farbe **und** eine Durchstreichung. Ein Zustand, der nur
> an der Farbe hängt, ist für einen Teil der Leser kein Zustand.

## Mehrzeilige Punkte

```md
- Ein Punkt, dessen Text so lang ist, dass er umbricht,
  und dessen zweite Zeile bündig unter der ersten steht.

- Ein Punkt mit einem eigenen Absatz.

  Der zweite Absatz gehört noch zum selben Punkt.
```

- Ein Punkt, dessen Text so lang ist, dass er umbricht,
  und dessen zweite Zeile bündig unter der ersten steht.

- Ein Punkt mit einem eigenen Absatz.

  Der zweite Absatz gehört noch zum selben Punkt.
