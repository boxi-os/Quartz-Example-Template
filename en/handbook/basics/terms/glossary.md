**Part** — one of the ten pieces a template package consists of. See
[[en/examples/index|Examples]].

**Frame** — the grid of a page: which areas there are and where they sit. This template brings
three: `editorial`, `index` and `focus`.

**Frame box** — the width, the alignment and the padding of a page grid, set separately per screen
width. It decides how wide the text gets.

**Token** — a named CSS variable such as `--tpl-space-md`, which the design is made of.
