| Abbreviation | Meaning |
| ------ | --------- |
| AA | conformance level of the WCAG — the threshold this template measures against |
| CLI | command line interface: operating a program through typed commands instead of windows |
| CSS | Cascading Style Sheets: the language for the look of web pages |
| GFM | GitHub Flavored Markdown: a widespread Markdown variant with tables and task lists |
| HTML | HyperText Markup Language: the language of the web pages themselves |
| JSON | JavaScript Object Notation: a text format for data; canvas files are JSON |
| npm | the package manager through which Quartz and its plugins are installed |
| OFL | SIL Open Font License: the licence of the three typefaces of this template |
| PDF | Portable Document Format: documents that look the same everywhere |
| SCSS | Sassy CSS: CSS with variables and nesting, translated to CSS |
| SSG | static site generator: a program like Quartz |
| SVG | Scalable Vector Graphics: graphics made of lines and areas instead of pixels, enlargeable at will |
| TOC | table of contents |
| URL | Uniform Resource Locator: the address of a page |
| WCAG | Web Content Accessibility Guidelines: the guidelines for accessible websites |
| YAML | YAML Ain't Markup Language: the notation of frontmatter and configuration |

What an abbreviation *means*, when that is more than its expansion, stands in the
[[en/7-reference/01-glossary|Glossary]].
