Thirteen areas, one short page per element. The pattern is the same everywhere: the source in a
code block first, the rendered result directly below it.

> [!tip] Why the small pages
> One page per element can be linked to, found again in the explorer and looked up on its own. A
> long collected page can only be skimmed.
