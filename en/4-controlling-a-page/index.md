Every page here shows one special case.

- [[en/1-getting-started/04-how-a-page-is-built|A long article]] — headings down to the sixth level, so the table of
  contents on the right is filled completely
- [[en/4-controlling-a-page/04-custom-fields|Many properties]] — a full frontmatter
- [[en/4-controlling-a-page/03-aliases|A page with an alias]] — reachable under several paths
- [[en/4-controlling-a-page/05-layout-boxes-per-page|Controlling the layout box per page]] — the same component, set
  up differently

Two pages sit in the folder but never appear:

- a **draft** (`draft: true`) is not built at all
- an **unlisted** page (`unlisted: true`) is built but appears in no listing — it can only be
  reached through its path
